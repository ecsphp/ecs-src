Fixer universe vs blink coverage
================================

The README parity is measured against the full fixer universe blink draws
from: every PHP-CS-Fixer fixer, every Symplify coding-standard fixer, and the
PHP_CodeSniffer sniffs ECS references from its sets. That universe is generated
by cmd/list-universe into ecs-all-fixers.txt; bin/rule-counts.sh keeps the
counts in the README current. blink is a subset of the universe, so coverage
never exceeds 100%. List the universe fixers blink has not ported yet with:

  comm -23 <(sort -u blink/ecs-all-fixers.txt) \
           <(./blink list-checkers | sed 's/^[[:space:]]*-[[:space:]]*//' | sort -u) \
    | sed -E 's#.*\\##'

Every fixer/sniff ECS actually enables in a set is implemented; the remaining
universe backlog is PHP-CS-Fixer fixers no ECS set turns on.

A few "missing" names below are already implemented under the fixer's newer
PHP-CS-Fixer name and only differ by alias:
  CurlyBracesPositionFixer          -> BracesPositionFixer (done)
  CompactNullableTypehintFixer      -> CompactNullableTypeDeclarationFixer (done)
  NoSpacesInsideParenthesisFixer    -> SpacesInsideParenthesesFixer (done)
  FunctionTypehintSpaceFixer        -> TypeDeclarationSpacesFixer (done, deprecated alias)

PsrAutoloadingFixer reads the file path, which the runner records on the stream
(Stream.Path); it is opt-in only (not in any default set, excluded from per-cs).


NOT YET IMPLEMENTED (behavior)

PsrAutoloading, runs off Stream.Path.

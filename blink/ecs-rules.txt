ECS rules NOT yet implemented in blink
=======================================

Source: every Fixer/Sniff referenced across ecs-src config/set/* and
src/Config/Level/*, listed in ecs-all-fixers.txt. Fixers that implement
PHP-CS-Fixer's DeprecatedFixerInterface are excluded (not counted, not ported).

207 rules configured in ECS. The live implemented/missing counts are in the
README (bin/rule-counts.sh keeps them current). Regenerate the list below with:

  comm -23 <(sort -u blink/ecs-all-fixers.txt) \
           <(./blink list-checkers | sed 's/^[[:space:]]*-[[:space:]]*//' | sort -u) \
    | sed -E 's#.*\\##'

A few "missing" names below are already implemented under the fixer's newer
PHP-CS-Fixer name and only differ by alias:
  CurlyBracesPositionFixer          -> BracesPositionFixer (done)
  CompactNullableTypehintFixer      -> CompactNullableTypeDeclarationFixer (done)
  NoSpacesInsideParenthesisFixer    -> SpacesInsideParenthesesFixer (done)
  FunctionTypehintSpaceFixer        -> TypeDeclarationSpacesFixer (done, deprecated alias)

PsrAutoloadingFixer reads the file path, which the runner records on the stream
(Stream.Path); it is opt-in only (not in any default set, excluded from per-cs).

PsrAutoloading, runs off Stream.Path.

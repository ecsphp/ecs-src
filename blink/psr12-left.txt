PSR-12 rules left to implement
==============================

Reference: PHP-CS-Fixer @PSR12 = @PSR2 (+ @PSR1) plus extra rules.
Below: what is still partial or bounded in blink. Everything else in @PSR-12
is implemented (see bottom).


PARTIAL
-------
method_argument_space           single-line comma spacing is done; the multi-line
                                "one argument per line" reflow is not
ordered_class_elements          conservative: skips any class containing comments
                                or attributes (attributes lex as # comments here),
                                reordering only simple classes. Broadening it needs
                                first-class attribute tokens.


LEFTOVERS (bounded / low value)
-------------------------------
binary_operator_spaces          arithmetic/bitwise (+ - * / % & | ^): unary-
                                ambiguous, need operand context (=, =>, comparison
                                and logical operators are done)

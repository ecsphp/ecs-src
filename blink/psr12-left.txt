PSR-12 rules left to implement
==============================

Reference: PHP-CS-Fixer @PSR12 = @PSR2 (+ @PSR1) plus extra rules.
Below: what remains NOT implemented in blink. 47 fixers are done (see bottom).

A statement/scope layer exists: Stream.MatchForward/MatchBackward, classifyBrace
(labels each "{"), and classMemberStarts (iterates class members). The rules
below need more of it (member reordering, type spans) or a fuller type model.


NEEDS FULLER AST / TYPE MODEL
-----------------------------
function_declaration            "function" signature spacing, closures
compact_nullable_type_declaration   "? int" -> "?int" in type positions
modifier_keywords               modifier ordering (casing/presence done)
new_with_parentheses            "new Foo" -> "new Foo()" (needs class-name ctx)

Notes:
- method_argument_space is implemented for single-line comma spacing only; the
  multi-line "one argument per line" reflow is not done.
- ordered_class_elements is conservative: it skips any class containing comments
  or attributes (attributes lex as # comments here), reordering only simple
  classes. Broadening it needs first-class attribute tokens.


LEFTOVERS (bounded / low value)
-------------------------------

binary_operator_spaces          arithmetic/bitwise (+ - * / % & | ^): unary-
                                ambiguous, need operand context
